# AI Bookmark Manager — 分阶段开发实施指导书

> 本文件为开发 Agent 的唯一阶段执行基线。任何阶段开始前必须阅读本指南并对照当前阶段任务清单。

本仓库执行的是以下开发指导（完整版）：

| 项 | 描述 |
|---|---|
| 项目目标 | 本地优先的 Chrome/Edge 书签管理扩展；原生书签默认只读，只有经用户批准的 `OperationPlan` 可写入。 |
| 当前阶段 | **阶段 4 前置基线：已完成 Phase 0–3，等待 P4 实施** |
| 阶段顺序 | `0 → 1 → 2 → 3 → 4 → 5 → 6 → 7`（阶段 3 与 4 允许在 2 稳定后并行） |
| 交付约束 | 每次提交需回答：改动文件、需求编号、命令及结果、测试结果、浏览器验收状态、已知风险、Commit 哈希。**不得虚构测试通过或构建成功。** |

## 阶段总览

| 阶段 | 主题 | 目标 | 关键产物 |
|---|---|---|---|
| 0 | 审计 + 质量基线 | 能构建、能运行、能读真实书签 | `docs/audit-phase0.md`、CI、README、ADR-001~003 |
| 1 | 书签数据 + UI 完整化 | 10,000 条模拟数据无丢失；事件驱动对账 | `BrowserBookmarksAdapter`、Dexie v1、UI、JSON 导出 |
| 2 | 备份恢复 + 受控操作底座 | 0 未批准写入；操作可追踪 | `OperationPlan/Step/Approval/Snapshot`、`OperationExecutor` |
| 3 | 链接检测 | 状态可解释；中断可恢复 | `URLGuard` + `FetchClient` + `HealthClassifier` + 任务队列 |
| 4 | 规则整理 + 重复检测 | 不依赖 AI 的高质量建议 | URL 规范化、去重分组、建议中心 |
| 5 | AI Provider + 分类 | BYOK；不触碰裸写入 | `AIProvider` 抽象、分类建议、200 条标注集评估 |
| 6 | Agent 问答 + 整理计划 | 自然语言查询 + 安全计划 | 工具注册表、计划预览、一次性批准令牌 |
| 7 | 正文索引 + 语义检索 + 发布 | 真实浏览器可发布 | 混合检索、隐私审查、商店素材 |

## 红线（不可违反）

1. 未获用户批准不得删除、合并、批量移动、重命名原生书签
2. 默认不上传用户书签、网页正文、Token、API Key 到任何第三方
3. 不得将大模型返回的参数直接传入 `chrome.bookmarks` 写入接口
4. 单次 403/404/超时/DNS 失败不得自动删除书签
5. MV3 Service Worker 任务必须可中断、幂等、可恢复
6. 导出文件、日志、UI 不得意外泄漏 API Key
7. 禁止远程托管的可执行代码或动态注入远程脚本
8. 对外网请求严格控制协议、域名、并发、超时、重定向和响应体大小

## Agent 停止条件

任何阶段出现以下情况必须停止并反馈：

- 构建失败且无法定位
- 真实书签可能丢失
- 需要扩大权限但没有用户批准
- 模型调用可能泄露隐私
- 数据库迁移存在不可逆风险
- 操作执行器绕过确认
- 任务队列可能重复执行删除

---

**完成定义**：源码可构建、测试可复现、浏览器可验证、操作可恢复、用户可理解限制。
